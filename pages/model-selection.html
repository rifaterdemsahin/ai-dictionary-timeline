1. Image Keyframe Generation Models (Start & End Frame Conditioning) 00:00 Hook • 00:16 Resolution
ByteDance Seedream 4.0 / Flux Schnell via fal.ai
✔ Selected (Primary Keyframe Engine)
Cost per Keyframe: $0.003 - $0.010
Cost per 16s Short: $0.020 (2 frames)
Generation Latency: 1.2s - 1.8s
Native Aspect Ratio: 9:16 (1080x1920)
Seed Reproducibility: 100% Deterministic
Selection Rationale:
  • Geometric & Technical Adherence: Outstanding fidelity rendering technical diagrams, neural architecture topologies, and Claude SDK code snippets without illegible gibberish.
  • Seed Consistency Across Frame Pairs: Deterministic seed locks guarantee color palette and character posture continuity from initial state (00:00) to resolved architecture (00:16).
  • Cost Efficiency: At ~$0.010 per 9:16 high-res image, generates both keyframes for $0.02 total—enabling high-frequency iteration without budget friction.
  • Native 9:16 Vertical Composition: Zero letterboxing or unwanted focal cropping on mobile devices.
Flux.1 Pro Black Forest Labs / fal.ai
⚡ Benchmarked (High-Fidelity Fallback)
Cost per Keyframe: $0.050
Cost per 16s Short: $0.100 (2 frames)
Generation Latency: 4.5s
Typography Adherence: Exceptional
Evaluation & Role:

Unmatched in rendering complex English typography directly inside visual layouts. Used as a targeted fallback for concepts requiring precise terminal UI text rendering that cannot be synthesized via CSS overlays alone.

Midjourney v6 Midjourney Inc.
✖ Rejected for Production
Cost per Image: ~$0.050 - $0.080
Public API: None (Discord wrapper only)
Queue Latency: 35s - 60s
Rejection Rationale:

No official developer REST API violating programmatic MCP automation principles. Unofficial Discord bot wrappers risk Terms of Service suspensions and suffer unacceptable queue latencies (>45s). Over-stylized aesthetic lacks clear technical diagrammatic precision.

DALL-E 3 OpenAI
✖ Rejected for Production
Cost per Image: $0.040 - $0.080
Prompt Rewriting: Enforced LLM Mutator
Seed Consistency: Poor / Non-deterministic
Rejection Rationale:

DALL-E 3 internally rewrites input prompts via an LLM safety layer, distorting precise technical instructions into generic artistic interpretations. 4x more expensive than Seedream 4.0 with zero dual-frame seed continuity.

2. First-to-Last Frame Video Interpolation Models Dynamic Motion • State Morphing
Kling 1.6 Pro (Image-to-Video & Keyframe) Kuaishou / via fal.ai
✔ Selected (Primary Video Motion Engine)
Cost per 5s Clip: $0.070 - $0.090
Cost per 16s Short: $0.250 (3 transitions)
Dual Keyframe Conditioning: Supported (Start + End Frame)
Output Resolution: 1080p 9:16 Vertical Native
Selection Rationale:
  • Deterministic Boundary Conditioning: Accepts both start_image_url and end_image_url, guaranteeing that video motion begins strictly at the initial problem state and resolves cleanly at the final certification architectural takeaway.
  • Low Morph Distortion: Smoothly simulates 3D camera dollies, node network pulses, and token flow transitions without grotesque hallucinatory object warping.
  • Predictable API Pricing on fal.ai: ~$0.08 per 5s segment with fast warm-pool inference queues.
Luma Dream Machine 1.5 Keyframe Luma AI / via fal.ai
⚡ Benchmarked (Alternative Engine)
Cost per Clip: $0.080
Camera Dynamics: High (Cinematic sweeping)
Geometric Stability: Moderate
Evaluation & Role:

Superb cinematic 3D camera fly-throughs. Occasionally exhibits elastic shape transformations on rigid technical UI elements, making it best suited for organic concept transitions rather than structured cloud architecture diagrams.

Runway Gen-3 Alpha RunwayML
✖ Rejected (Cost Inefficiency)
Cost per 5s Clip: $0.250 - $0.500
Cost per 16s Short: $1.00 - $1.50
Economic Multiplier: 4.5x More Expensive
Rejection Rationale:

At $0.25–$0.50 per 5 seconds, Runway Gen-3 pushes the cost per 16-second short above $1.20, destroying the unit economics required for scalable curriculum generation. The marginal fidelity gain does not improve student comprehension or conversion.

3. Voiceover & Acoustic Speech Synthesis Models Kinetic Subtitles • Authority • Pacing
ElevenLabs Flash v2.5 / Turbo v2.5 ElevenLabs API
✔ Selected (Primary Voiceover Engine)
Cost per 16s Narration: $0.015 - $0.030
Word-Level Timestamps: Native Millisecond Alignment
Latency: < 120ms (Turbo Engine)
Remotion Integration: Direct Kinetic Sync
Selection Rationale:
  • Programmatic Alignment Arrays: Returns word-by-word start and end timestamps directly in the JSON response payload. This eliminates the need for a secondary Whisper transcription pass to align Remotion kinetic subtitles.
  • High-Retention Conversational Cadence: Pacing and natural micro-inflections hold viewer attention through the critical 00:00–00:04 hook window on YouTube Shorts.
  • Sub-Bass Ducking Compatibility: Clean vocal isolation frequencies allow Remotion's side-chain compressor to dip background music by 88% cleanly without audible pumping.
OpenAI TTS-1 / TTS-1-HD OpenAI
✖ Rejected as Primary (No Word Timestamps)
Cost per Clip: $0.003 - $0.006
Word Timestamps: None (Audio only)
Hidden Complexity: Requires Whisper ($0.006 + 5s latency)
Rejection Rationale:

While OpenAI TTS-1 has attractive raw audio pricing ($0.015/1k chars), the API does not provide word-level timestamp alignment. Syncing karaoke subtitles in Remotion requires running an extra Whisper STT pass, adding pipeline latency and fragility.

Remotion (React Video Framework on AWS Lambda) Remotion Open Source
✔ Selected (Programmatic Video Engine)
Cost per Render: $0.005 (AWS Lambda) / $0.00 (Local)
Render Time: 3.5 seconds @ 30 FPS
Audio Ducking: Deterministic Side-Chaining

Replaces costly SaaS video rendering services ($0.15/minute) with pure React/TypeScript code. Supports programmatic audio side-chain ducking (BGM volume drops to 12% during voiceover), CSS spring typography animations, and instant CI/CD deployment.

4. Azure Key Vault Integration Architecture Security • Zero Hardcoded Secrets

Automated Secret Resolution Workflow

dp-kv-deliverypilot.vault.azure.net

All API keys (ELEVENLABS-API-KEY, FAL-AI-KEY) are dynamically fetched via DefaultAzureCredential from Azure Key Vault without storing credentials in source control.

# scripts/azure_vault.py excerpt from azure.identity import DefaultAzureCredential from azure.keyvault.secrets import SecretClient credential = DefaultAzureCredential() client = SecretClient(vault_url="https://dp-kv-deliverypilot.vault.azure.net", credential=credential) elevenlabs_key = client.get_secret("ELEVENLABS-API-KEY").value
Verified in automated pipeline: scripts/elevenlabs_generate.py synthesizes MP3 audio streams alongside Remotion word-level timing JSON in outputs/audio/.

📐 Deterministic Boundary Conditioning

Unlike unconditioned text-to-video generation which wanders visually, this pipeline locks the start image (00:00) to the conceptual problem hook and the end image (00:16) to the certification architectural takeaway. Kling 1.6 Pro performs non-linear trajectory interpolation between fixed states.

🎧 Frequency-Isolated Audio Bus

Remotion’s audio pipeline implements strict frequency slotting:

  • 20–70 Hz: Sub-bass whoosh transition impacts
  • 100–300 Hz: Brian’s 112 Hz baritone vocal body
  • 1–4 kHz: Consonant intelligibility and UI alerts
  • 6–20 kHz: BGM bed ducked by -18 dB during speech

🔐 Zero-Trust Key Vault Security

All API secrets (ELEVENLABS-API-KEY, FAL-AI-KEY) are dynamically resolved via Azure Managed Identity or Azure CLI credentials. No plaintext API keys are ever committed to git or stored in static client bundles.
